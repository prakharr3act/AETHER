# AETHER

 Responsive art gallery website with dark/light mode and immersive visual design.

![Preview](https://images.unsplash.com/photo-1579783902614-a3fb3927b6a5?auto=format&fit=crop&w=1200&q=80)

## Features

- Responsive on all devices
- Dark & light theme toggle
- LocalStorage theme saving
- Modern minimal UI
- Smooth animations
- Gallery layout
